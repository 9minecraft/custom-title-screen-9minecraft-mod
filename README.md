# Custom Title Screen 9minecraft Mod - Add Clickable Links to Menus

Custom Title Screen 9minecraft Mod puts custom text lines across the main menu and pause screen corners. It lets you display server IP addresses, pack versions, welcome notes, or web links directly on your menus. The text works with custom colors, styles, and clickable actions without touching standard game buttons. Features: Places custom text lines in the four corners of the title screen and pause menu. Works with standard Minecraft text formatting, including hex colors, bold, italic, and underline styling.
